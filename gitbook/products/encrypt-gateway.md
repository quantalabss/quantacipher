# QuantaCipher Encrypt & Ingest Gateway

The **QuantaCipher Ingest Gateway** provides an enterprise edge interface for registering post-quantum ciphertexts, enforcing organizational quotas, and anchoring cryptographic receipts to Sigstore Rekor.

---

## 1. Gateway Endpoint Specification

### `POST /api/v1/ingest`

Receives an encrypted ciphertext envelope from the QuantaCipher SDK, validates the formatting, logs non-repudiation metadata, and anchors the proof to the Rekor Merkle tree.

#### Headers:
| Header | Value | Required | Description |
|---|---|---|---|
| `Authorization` | `Bearer qz_live_...` | Yes | Valid production or staging API key. |
| `Content-Type` | `application/json` | Yes | Must be JSON. |

#### Request Body:
```json
{
  "ciphertext": "QZ_VAULT_V2:ml-kem-1024:k4b2...:9f8a...:d7e1...",
  "timestamp": 1794749800000
}
```

#### Field Specifications:
* `ciphertext` (`string`, required): A valid QuantaCipher post-quantum envelope string. Must begin with one of:
  * `QZ_VAULT_V2:`
  * `QZ_SECURE_V2:`
  * `QZ_VAULT_V1:`
  * `QZ_SECURE_V1:`
  * `QZ_TRUE_PQC_KEM:`
* `timestamp` (`number`, optional): Unix epoch millisecond timestamp generated by the client.

---

## 2. Success Response: HTTP 200 OK

```json
{
  "success": true,
  "receipt": {
    "id": "qz_rcpt_1753429812_abc123",
    "timestamp": "2026-11-16T04:57:00.000Z",
    "bytesSecured": 256,
    "encryptionScheme": "ML-KEM-1024 (FIPS 203) + AES-256-GCM",
    "mode": "vault",
    "rekorLogId": "c09268f7734891b2e65...",
    "rekorIndex": 481093
  }
}
```

---

## 3. Error Responses

### HTTP 400 Bad Request — Plaintext or Invalid Envelope
If a developer accidentally sends raw unencrypted text to the endpoint:

```json
{
  "error": "Invalid payload format",
  "message": "Ciphertext must be encrypted using the QuantaCipher SDK (ML-KEM-1024 or ML-KEM-768, FIPS 203). Raw plaintext is rejected.",
  "acceptedFormats": [
    "QZ_VAULT_V2:",
    "QZ_SECURE_V2:",
    "QZ_VAULT_V1:",
    "QZ_SECURE_V1:",
    "QZ_TRUE_PQC_KEM:"
  ]
}
```

### HTTP 401 Unauthorized — Missing or Invalid Key
```json
{
  "error": "Unauthorized",
  "message": "Invalid or revoked API key provided in Authorization header."
}
```

### HTTP 429 Too Many Requests — Quota Exceeded
```json
{
  "error": "Quota Exceeded",
  "message": "Monthly secured bandwidth quota exceeded. Please upgrade your tier in the dashboard."
}
```
