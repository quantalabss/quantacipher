# QuantaCipher Sign & Zero-Trust Verification

The **QuantaCipher Sign & Verification API** enables distributed microservices, API Gateways, and reverse proxies to verify post-quantum digital signatures without holding private keys or managing complex WebAssembly toolchains.

---

## 1. Zero-Trust Verification Architecture

In a distributed service architecture, client applications sign their requests locally using a private key. Downstream edge proxies (or the QuantaCipher Gateway) verify authenticity using only the public key:

```
[Client App] ── 1. Sign Payload Locally (ML-DSA PrivKey) ──┐
                                                           │
                                                           ▼
[Edge Gateway] ◄── 2. Request + SignatureEnvelope + PublicKey
      │
      ├── 3. Verify via QuantaCipher WASM Engine (No Private Key)
      ▼
[Success: HTTP 200 / Authorized]
```

---

## 2. Verification Endpoint Specification

### `POST /api/v1/verify`

#### Headers:
| Header | Value | Required |
|---|---|---|
| `Authorization` | `Bearer qz_live_...` | Yes |
| `Content-Type` | `application/json` | Yes |

#### Request Body:
```json
{
  "payload_b64": "SGVsbG8gUG9zdC1RdWFudHVtIFdvcmxk",
  "signature_json": "{\"alg\":\"ml-dsa-44\",\"sig\":\"R9a...b2c\",\"ver\":1}",
  "public_key_b64": "E9f8...base64_public_key..."
}
```

#### Field Specifications:
* `payload_b64` (`string`, required): Standard base64-encoded representation of the original signed payload.
* `signature_json` (`string`, required): Canonical JSON serialization of the `SignatureEnvelope` generated by `signer.envelopeToJson()`.
* `public_key_b64` (`string`, required): Base64-encoded public verification key of the signer.

---

## 3. Response: HTTP 200 OK

```json
{
  "verified": true,
  "algorithm": "ml-dsa-44",
  "version": 1
}
```

If the signature was forged or computed over different data, `verified` returns `false`:

```json
{
  "verified": false,
  "algorithm": "ml-dsa-44",
  "version": 1
}
```

---

## 4. Error Responses

* **HTTP 400 Bad Request:** Missing fields, malformed JSON signature envelope, or unsupported algorithm.
* **HTTP 401 Unauthorized:** Invalid or revoked API key.
* **HTTP 500 Internal Server Error:** Unexpected server-side failure.
